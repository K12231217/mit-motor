# 毕业设计研究方案：关节驱动器设计与三相电流可信自校准

**版本**：V1.1（2026-11-04：料号修正为 G491RCT6；重构与标定的边界澄清）  
**日期**：2026-11-04  
**毕业设计题目**：基于 STM32G491 与 MP6540HA 的关节驱动器设计及三相电流可信自校准  
**研究性质**：本科毕业设计，强调系统设计、方法研究与实现验证，不以高水平期刊指标为导向

## 一、研究背景

关节电机驱动器是机器人关节实现位置、速度和转矩控制的核心部件，其性能不仅取决于功率器件和控制算法，还依赖于电流、位置等反馈信息的准确性与可信度。电流反馈既是磁场定向控制的基础，也是转矩估计、过载保护和故障判断的重要依据。当电流测量出现偏置、增益失配或采样失效时，控制器可能仍然保持闭环运行，但实际电流和输出转矩已经与控制器估计值产生偏差。

传统电机驱动器通常采用外部分流电阻和电流放大器进行相电流检测。集成三相驱动器 MP6540HAA 将功率 MOSFET、栅极驱动和比例电流检测集成在单芯片内，能够减少功率分流电阻及其布局面积，适合空间受限的关节驱动器。但这种集成方案也带来了新的问题：三路比例电流输出可能存在不同的零位和增益；电流检测只在低边电流路径有效时提供可靠信息；采样时刻、前端建立时间和 ADC 触发时序会影响测量有效性。

进一步地，三相三线电机满足相电流之和为零，可以利用这一物理约束对三路电流测量进行相互校准。然而，简单的在线校准并不意味着校准结果一定可信。当采样窗口无效、激励方向不足或某一测量通道突然变化时，估计器可能输出不稳定参数，甚至将故障逐渐学习为新的校准状态，使故障残差消失。因此，有必要在研究相对增益校准方法的同时，研究采样有效性、激励充分性以及异常时的校准冻结和故障处理。

本毕业设计以自研关节驱动器为载体，围绕“驱动系统实现—电流测量校准—异常可信处理”开展研究，形成从硬件、固件到算法和实验验证的完整工作链条。

## 二、研究目标

1. 设计并实现基于 STM32G491RET6 与 MP6540HA 的关节电机驱动系统，具备基本的 FOC／MIT 控制、位置反馈、通信和保护能力。
2. 建立三路低边比例电流检测的误差与采样模型，研究适用于嵌入式平台的相对增益自校准方法。
3. 研究校准过程中的异常识别与冻结机制，避免无效数据和突发测量故障引起错误参数更新。
4. 通过静态、低速和物理增益故障注入实验验证系统功能，明确方法的适用范围与局限。

## 三、研究内容

### 研究内容一：关节电机驱动系统总体设计与实现

围绕关节驱动器的功率、控制、传感和通信需求，完成以 STM32G491RCT6 为主控、MP6540HA 为三相功率驱动核心的硬件设计。研究三路 SOx 比例电流输出与三 ADC 的接口方式，完成双 MT6701 位置传感器、CAN FD、母线采样、温度检测和保护电路的系统集成。

在固件方面，建立 PWM 输出、ADC 触发、编码器读取、坐标变换、电流环和速度／位置控制等基本模块，形成 FOC／MIT 控制底座；同时设计原始数据记录和故障状态输出功能，为后续校准与异常实验提供统一平台。该部分重点解决系统各模块之间的时序配合、数据有效性和基本控制运行问题。

### 研究内容二：三相低边比例电流采样与相对增益自校准方法研究

建立包含通道零位、相间增益差异、量化噪声和低边采样窗口的三相电流测量模型。利用三相三线系统相电流之和为零的约束，在零位校准和有效数据筛选的基础上，研究三路相对增益的估计方法。

针对固定转子单一电流矢量无法充分辨识相间增益的问题，设计多方向、多幅值的电流激励，分析数据激励条件与估计稳定性之间的关系。研究三 ADC 同时采样与顺序采样对**测量残差**的影响，以及两相重构对**控制环残差**的影响；标定一律使用三路独立采样，禁止用重构值构造零和约束。并采用外部电流参考对校准结果进行验证。该部分只研究相对增益和测量一致性，不将零和约束扩展为无需外部基准的绝对电流或绝对转矩标定。

### 研究内容三：面向测量异常的校准冻结与故障安全处理研究

研究在线校准与故障检测之间的相互影响，重点分析测量通道突然变化时，在线估计器通过调整参数吸收故障、使残差重新下降的问题。建立数据无效、激励不足、正常参数更新和异常冻结等不同状态，形成“先检查、后更新；先冻结、后诊断”的处理流程。

在验证方法上，通过 SOx 小信号终端网络构造可重复的物理增益变化，并结合软件故障注入扩展故障类型，比较普通在线校准与加入有效性判断、激励判断和异常冻结后的处理差异。对于确认影响控制安全的传感故障，系统进入故障锁存和关断流程，不采用预测电流或预测角度继续带载运行。

## 四、拟采用的技术路线

### 4.1 总体路线

按照“平台构建—模型建立—校准估计—异常处理—实验验证”的顺序开展：

```text
关节驱动需求分析
        │
        ▼
驱动板硬件设计与 G491 引脚、ADC 时序核查
        │
        ▼
FOC／MIT、编码器、通信与数据记录固件
        │
        ▼
SOx 零位、增益和低边有效窗口建模
        │
        ▼
多方向电流激励与相对增益约束估计
        │
        ▼
采样有效性判断＋激励充分性判断
        │
        ▼
异常残差监视、校准冻结与故障确认
        │
        ▼
外部电流参考＋物理增益注入＋系统功能验证
```

### 4.2 具体方法

1. **硬件与底层驱动方法**  
   依据器件手册完成原理图和 PCB 设计，首先核查 G491RET6 的三 ADC 引脚分配、共同定时器触发和采样保持过程，再开展功率级和保护链调试。软件采用分层结构，将功率控制、传感采样、校准估计和故障管理分离。

2. **同步采样与有效性标记方法**  
   以 PWM 周期为时间基准，为每组三相电流数据附加采样有效标志。只有低边测量路径有效、前端完成建立且三路数据时间对齐时，数据才进入校准器；无效数据只被跳过，不用于构造虚假约束。

3. **相对增益约束估计方法**  
   对第 \(k\) 组采样，建立：

   \[
   y_{j,k}=o_j+g_j i_{j,k}+e_{j,k},\qquad
   i_{a,k}+i_{b,k}+i_{c,k}=0
   \]

   在零位估计后，以归一化约束消除尺度任意性，采用约束最小二乘或等价数值方法求解相对系数。通过多方向电流激励保证数据包含足够信息，在激励不足或数据病态时保持原参数。

4. **异常冻结与故障管理方法**  
   使用当前确认参数进行快速残差检查，慢速校准任务只有在持续获得有效、充分且无异常的数据后才更新参数。状态按照“未校准—校准中—正常跟踪—冻结—故障”迁移，冻结后保留最后可信参数并禁止自动恢复，确认故障后执行相应关断。

5. **实验验证方法**  
   采用外部电流测量作为校准参考，使用多方向静态电流和低速运行数据验证标定一致性。通过成对改变 SOx 终端电阻构造物理增益变化，观察普通在线校准和可信校准方法的不同响应。实验重点在于验证方法过程、故障处理逻辑和适用边界，而非追求统一的性能数值指标。

## 五、可行性分析

1. **硬件可行性**：G491RET6 提供多路 ADC、定时器和数学加速资源，MP6540HA 集成三相功率级与双向低边比例电流检测，适合构建紧凑实验平台。
2. **算法可行性**：相对增益估计以线性测量模型和物理约束为基础，可采用成熟的约束最小二乘方法实现，计算量适合嵌入式平台。
3. **实验可行性**：主要研究可先在静止、限流和低速条件下进行，不依赖带载对拖；SOx 小信号网络为可重复物理增益注入提供了实现条件。
4. **工作量可行性**：毕设保留完整驱动系统，但论文式算法只集中于相对增益校准和异常冻结，避免同时扩展到热估计、力矩精密测量和其他故障诊断方向。

## 六、预期成果

- 一套自研关节电机驱动板及其控制固件；
- 三 ADC 电流采样、数据记录和基本保护模块；
- 三相电流相对增益自校准与异常冻结模块；
- 外部参考校准和物理增益故障注入实验记录；
- 本科毕业论文及相应设计图纸、程序与实验数据。

## 七、研究边界

本设计不宣称恢复绝对电流共同尺度，不宣称检测全部电流测量故障，也不把三 ADC 数量本身作为算法创新。绕组温度估计、精密动态转矩测量、双编码器故障可检测性和关断电流路径辨识均不纳入本毕业设计的主要研究内容。
