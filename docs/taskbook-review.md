# 外包任务书对抗审核（V2.0，2026-11-15）

> 审核对象：`Stm32g474_Mp6540ha_关节驱动板外包硬件设计任务书(1).md`
> 对照基线：[hardware-requirements.md](hardware-requirements.md)（HR-xxx）、[architecture.md](architecture.md)、PCB14 网表、CubeMX 器件库、MPS 官方资料。

## 0. 先说一条反转：任务书 §1 是对的，本仓库是错的

任务书说 **`MP6540HGU-A-Z` = MP6540HA = 独立 HS/LS 六输入**，并说 `MP6540H` 是 PWM+EN。
这条**成立**，证据三条：

| 来源 | 原文要点 |
|---|---|
| MPS 数据手册（MP6540H/MP6540HA，Rev 1.0）引脚表 | 6/7/8：`PWMA/PWMB/PWMC`（H）与 **`HSA/HSB/HSC`（HA）** 二选一列在同一行 |
| MPS 技术论坛 topic 5570（任务书自己引的那条）| "if you order an **MP6540HGU-A-Z** you get an **MP6540HA**. If you want an MP6540H, you better order an **MP6540HGU-P**" |
| 厂商摘要（Electronics-Lab）| "MP6540H has enable (EN) and PWM inputs … MP6540HA has separate high-side (HS) and low-side (LS) inputs, otherwise identical" |

于是 [architecture.md](architecture.md) §2.2 的"BOM 实发 H 版、pin 3/4/5 = ENA/B/C、原理图命名有误导性"
**是错的**：pin 3/4/5 是 `LSA/LSB/LSC`，PCB14 网表里的 `PWM_AL/BL/CL` 命名本来就是对的。

后果不是文档问题，是**炸板风险**：按 §2.1 把 PA7/PB14/PB15 当 EN 拉高、再让 TIM1 输出 PWM，
等于三相低边**常通**，上管一开通就是直通。任何沿用 §2.1 写的固件都必须先停。

已按此修正：本文档 §1、[architecture.md](architecture.md) §2.1/§2.2/§8、[hardware-requirements.md](hardware-requirements.md) HR-302/403/408。

派生结论（任务书里没写、但必须写进外包文件）：

- **死区必须由 MCU 产生**（TIM1 BDTR），HA 没有内部死区逻辑；数值要给定（建议 200–500 ns，按 MP6540H 的 t_d 与开关时间定），且死区会吃掉采样窗口。
- **故障语义变了**：6 路全无效 = 上下管全关 = **自由停车**，不是刹车。"BKIN 是低边常通、必须靠 EN 拉低"这条在 HA 上不成立。
- `nSLEEP` 仍是真正的关断，保留 10 kΩ 下拉。

## 1. P0：照此投板会不能用

### P0-1 三抢五脚：`FDCAN2` / `ADC4` / `TIM1_CH1N~3N` 无解

任务书同时要求：CH1N~3N = `PB13/PB14/PB15`、EXT_I_REF = `PB12 或 PE14`(ADC4)、双路 CAN FD。
实际可用的脚：

| 需求 | 唯一可用引脚 | 冲突 |
|---|---|---|
| `ADC4` 模拟输入（LQFP64 只有 3 个）| **PB12** / PB14 / PB15 | PE14 在 LQFP64 **不存在**；PB14/15 被 N 通道占 |
| `TIM1_CH1N` | PA7 / **PB13** / PC13(3 mA 弱) / PA11(USB) | PA7 被 SOB 占 → 只剩 PB13 |
| `FDCAN2` | **PB12/PB13** 或 PB5/PB6 | 前两个被上面吃掉 |

**任务书全文没有一处写 CAN 接哪两个脚**，也没写 USART 接哪两个脚——按这份文件外包只能自己猜。

**可落地的分配**（我已逐脚核对，可直接抄进任务书）：

| 功能 | 引脚 | 备注 |
|---|---|---|
| HS_A/B/C | PA8/PA9/PA10 | TIM1_CH1/2/3 |
| LS_A/B/C | **PB13/PB14/PB15** | TIM1_CH1N/2N/3N，BDTR 死区 |
| SOA / OPAMP1 | PA1 | ADC1_IN2 / OPAMP1_VINP / COMP1_INP |
| SOB / OPAMP2 | PA7 | ADC2_IN4 / OPAMP2_VINP / COMP2_INP |
| SOC / OPAMP3 | PB0 | ADC3_IN12 / OPAMP3_VINP / COMP4_INP |
| EXT_I_REF（ADC4）| **PB12** | ADC4_IN3，唯一选择 |
| FDCAN2_RX/TX | **PB5 / PB6** | 代价：SPI1 不能用 PB5 当 MOSI |
| SPI1_SCK/MISO | PB3 / PB4 | MT6701 是只读 3 线，**不需要 MOSI** |
| CS_ENC1 / CS_ENC2 | PB7 / PB9 | |
| USART3_TX/RX | **PC10 / PC11** | PB10 让给 BKIN |
| TIM1_BKIN | **PB10** | nFAULT 的开漏输出接这里；PA11 是 BKIN2 且是 USB_DM，不能用 |
| nFAULT 软件可读 | **PC9**（与 PB10 同网络）| 见 P1-2 |
| USB_DM/DP | PA11 / PA12 | 任务书完全漏了 USB |
| nSLEEP | PC5 | 10 kΩ 下拉 |
| DAC1_OUT1/2 | PA4 / PA5 | 虚拟示波器 |
| LED | PB2 | 状态指示 |
| BOOT0 | PB8 + 10 kΩ 下拉 | 任务书漏了，缺了可能不启动 |
| 三相输出 | 3×2 pin 端子 | 任务书漏了，见 P0-3 |

### P0-2 `VREF+` 引脚号错，且这个错会传染

任务书写 **"VREF+（Pin 20）"**。LQFP64 的 VREF+ 是 **Pin 28**（19/20 是 PA0/PA6；PCB14 网表里 `U1.28` 就在 +3V3 上）。
Pin 20 = `PA6` = `OPAMP2_VOUT`，任务书自己在第 3 节还要求 PA6 悬空——两处自相矛盾。
这条大概率是从 **48 脚 CBT6** 的资料抄过来的（那里 VREF+ 是 20），和 `PE14` 是同一类错误：
**任务书里混进了非 64 脚的引脚事实**，外包照着做会把 3V3 直接灌到 PA6。

### P0-3 没有三相输出端接、没有功率输入连接器、没有分流位置 ⇒ 论文实验 E1 做不了

任务书 §5 只写了"对外接口"：SWD+UART、2×CAN、编码器 SPI、EXT_I_REF。
**没有**：三相输出端子、母线输入连接器（XT30/端子）、每相串联分流位置。
外部基准（INA240）要串在相线上，没有断点就只能飞线；而"台架逐相逐点标定"是本课题的核心实验。

### P0-4 没有 USB

任务书全文没有 USB。毕设要求 USB FS 上位机 GUI + trace 上传（[architecture.md](architecture.md) §3），
PA11/PA12 是唯一落点，且 **PA11 同时是 TIM1_BKIN2**——任务书把 BKIN 推荐到 PA11，等于砍掉 USB。

## 2. P1：会返工

| # | 任务书说法 | 事实 | 改法 |
|---|---|---|---|
| P1-1 | 增益注入"上下各**串联** 47 kΩ … 等效增益**下降 −9.6%**" | 4.99k **串** 47k ⇒ Rth 从 2.495k 变 25.995k，增益 **×10.4(+940%)**，±0.5 A 就打满轨。−9.6% 只有**并联**才成立：`4.99∥47 = 4.52k`，Rth 2.258k（−9.5%）| 写"并联 47 kΩ"，并在 PCB 上用并联焊盘；或直接给更换值（4.02k=+15% 增益需 Rth 2.87k… 见表 §4）|
| P1-2 | nFAULT 接 TIM1_BKIN | 接了就**读不到**故障源：BKIN 是定时器输入，不是可读 GPIO。而且 HA 的 nFAULT 复位行为需按手册确认（若随 PWM 边沿自清，硬件 BKIN 会变成逐周期封锁）| nFAULT 一个网络接**两个** MCU 脚：PB10(BKIN) + PC9(GPIO 读) |
| P1-3 | "nFAULT … 硬件 20ns 内封锁" | 20 ns 无出处：BKIN 有数字滤波（默认若干 TIM1 时钟）+ 定时器输出级延迟，加上 MP6540 自身 OCP 响应。量级应是 100 ns~1 µs | 写"≤1 µs"，验收用 LA 量 |
| P1-4 | 过压保护 | **整份任务书没有母线过压保护**（PCB14 有 TLV7021→BKIN）。24 V/28 V 母线、50 V 器件，丢掉 OVP 是安全回退 | 保留比较器硬保护（或内部 COMP+DAC），阈值 28.1 V ±2 %，TP 可测 |
| P1-5 | EXT_I_REF 连接器带 `VREF+` 引脚 | 把 ADC 基准引到电缆上＝把三路采样与全部标定的刻度接到一根跳线上。且外部基准板的 VREF+ 会倒灌 | 只出 `EXT_I_REF + GND`，加 100 Ω 串阻与钳位 |
| P1-6 | 滤波电容 `100 pF~220 pF`，τ≈0.25~0.55 µs | 220 pF 时 12 bit 建立 ≈9τ = 5 µs，等于占满 d=90 % 时的全部低边窗口，且还没算 SOx 放大器自身建立与死区 | 固定 **100 pF ±1 % C0G**，三通道同批；窗口余量写进验收（HR-305）|
| P1-7 | 偏置上拉接 `VREF+` | SOx 电流从 VREF+ 节点进出：±5 A 时每相 59~602 µA，三相约 1.6 mA 的**随电流变化**的基准负载。VREF+ 同时是 ADC 刻度 ⇒ 与电流相关的增益误差，且是非线性的，零位/增益标定吃不掉 | 要么偏置改由独立缓冲源（或 DAC）供电，要么在 VREF+ 上加 10 Ω+10 µF 隔离并**实测**该效应；不要假设为零 |
| P1-8 | "VREFBUF 2.9 V 可选" | 三路分压已耗 ≈0.87 mA，VREFBUF 带载能力与所需稳定电容必须按 DS 给值（不是随手 4.7 µF），且它与 ADC 基准共用会更抖 | 建议固定 VREF+ = VDDA，用 VREFINT 反算 VDDA（HR-810）；VREFBUF 仅作为实验选项并写明限制 |
| P1-9 | "TIM1_TRGO2 下实现**真正纳秒级**三路同步" | ADC1/2 属 ADC12 组，ADC3/4 属 ADC345 组，两组触发选择寄存器与时钟源独立。**跨组同拍不是手册承诺**，是必须实测的量 | 写成"目标偏斜 ≤50 ns，实测值写入验收记录"，并给实测方法（DAC 共点扫描）|
| P1-10 | 用 OPAMP 跟随器"彻底消除电荷回踢" | 100 pF 直接挂在引脚上，回踢电荷分流早就够用（5 pF 采样电容对 100 pF，跌落 5 %，2.2 µs 采样时间内 8.8τ 恢复）。跟随器真正的代价是**多一级 offset/drift**（本课题的被标定量），收益是带宽与抗扰 | 要么删掉跟随器（保留 100 pF），要么保留但写明"offset 进零位标定、需实测"，并给出 OPAMP→ADC 内部通道号 |
| P1-11 | `PA7 与 SOB 冲突` 与同表把 SOB 放在 PA7 | 是 48 脚稿的残留文字；逻辑上不矛盾（PA7 只作模拟，不作 PWM），但会被外包读成"禁用 PA7" | 删掉引号里的旧约束，改为"PA7 只作 SOB/OPAMP2 输入，不得作 PWM" |
| P1-12 | 24 MHz 晶振"确保 CAN FD 与 HRTIM/TIM1 采样时序无抖动" | 抖动由 PLL/时钟树决定，与 16/24 MHz 无关；而 170 MHz 下 **USB 48 MHz 仍只能靠 HSI48+CRS**（340 MHz VCO 无法整数分频）| 保留 24 MHz（无害），但删掉因果表述，并补 USB 时钟方案 |
| P1-13 | 8-Pin 1.27 mm 测试排针，线序 `GND\|SOA\|SOB\|SOC\|TP_LA\|DAC1\|DAC2\|TP_SYNC` | ①只 1 个 GND，20 kHz 大电流下探针地回路太长；②1.27 mm 孔无法插标准探针夹；③`TP_LA`/`TP_SYNC` 全文没有定义由谁产生；④缺 VBUS_SENSE/NTC/3V3/VREF+/nFAULT/EN | 改 **2.54 mm 1×13**：`GND,SOA,GND,SOB,GND,SOC,GND,LA_WIN,DAC1,DAC2,SYNC,GND,VBUS_DIV`；并定义 LA_WIN = TIM8_CH1（PC6）硬件输出，SYNC = ADC 触发 |
| P1-14 | MT6701 接 SPI1 带 `PB5=MOSI` | MT6701 是只读 3 线（CS/SCK/MISO），MOSI 纯浪费，且正好堵死 CAN 的 PB5 | 删 MOSI；外置编码器 SPI 限速 ≤2 MHz 并写清线长上限 |

## 3. P2：规格缺失（外包会自己填，验收无依据）

- **母线**：额定/绝对电压、输入连接器、母线电容总值与耐压、欠压/过压阈值、反接保护。
  现有文字只有"10uF/50V×4 + TVS"，没有额定母线电压这一最基本参数。
- **功率级数值**：死区时间、PWM 频率上限、相线载流与温升判据、MP6540 结温测点。
- **模拟前端**：ADC 时钟、采样时间、占空比上限 d_max、通道匹配（电阻写了 0.1 %，**电容容差没写**）。
- **电源**：5 V/3.3 V 的拓扑与电流、LDO 精度、上电时序（母线在、逻辑不在时 SOx 会经上拉倒灌 3V3）。
- **编码器**：磁铁规格、气隙、板载 MT6701 与磁铁的同轴度公差、下方是否挖空铺铜。
- **布局**：`Inner2 = VBUS + 3V3` 同层意味着模拟 3V3 被开关母线的铜包围；MT6701 在 Bottom 又"散热覆铜"，
  热与磁干扰叠加。建议 `Inner2 = VBUS`、3V3 单独铺、传感器下方**净空**、模拟前端划静区。
- **接口保护**：CAN 无 ESD/TVS/共模电感；USB 无 ESD；SWD 口用 GH1.25 需转接板才能接 ST-Link（建议 2.54 排针）。
- **验收清单**：任务书 §6 的三条很好，但必须加：VREF+ 脚号（28）、CAN/USART/BKIN 落位、BOOT0 下拉、
  三相输出端接、USB、以及"PB5/PB6 不得同时被 SPI 占用"。

## 4. 采样链数字复核（任务书给对了的部分 + 一个精度结论）

`V_SO = VREF/2 + I/9200 × Rth`，`Rth = 4.99k∥4.99k = 2.495k`：

| 量 | 值 | 说明 |
|---|---|---|
| 灵敏度 | 0.2712 V/A | 比 PCB14 的 0.109 V/A 高 2.5× |

| ±5 A 摆幅 | ±1.356 V | 0.294–3.006 V，不削顶 ✓ |
| 电气满量程 | ±6.08 A | 超出即贴轨 |
