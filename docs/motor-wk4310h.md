# 海泰机电 WK4310H 电机参数

> 来源：厂家规格表（型号 `WK4310H`）。本文件只记录铭牌事实与代码换算；控制策略阈值仍在
> `software/algorithms/src/motor/config_policy.rs`，不在这里复制。
>
> 代码落点：[`software/algorithms/src/motor/config_motor.rs`](../software/algorithms/src/motor/config_motor.rs) 的
> `WK4310H: MotorParams`。电流环 `CurrentLoop::new(WK4310H, …)` 直接消费。

## 4. 代码换算（不是铭牌值）

- **每相电阻**：`10.32 / 2 = 5.16 Ω`。假设星形、相间测量跨两相。
- **每相电感**：`4.76 mH / 2 = 2.38 mH`。星形、忽略互感；若实测相间包含互感，需用
  LCR 表按单相重测。
- **永磁磁链**：`ψ = Kt / (1.5 · p) = 0.23 / (1.5 × 14) = 0.010952 Wb`。
  这是 `CurrentLoop` 的 BEMF 前馈使用的 `flux_wb`。
- **Kt/Kv 一致性**：`60/(2π·43) = 0.2221 N·m/A`，与铭牌 `Kt = 0.23` 相差约 3.5 %。
  代码以铭牌 `Kt` 为准；若台架实测 `Kt` 更接近 `Kv`，改 `KT_NM_PER_A` 后重新生成
  `FLUX_WB`，不要两处各改一份。
- **转子惯量**：`161 g·cm² = 1.61e-5 kg·m²`。

## 5. 对代码的影响

- `MotorParams { r_ohm, ld_h, lq_h, flux_wb }` 使用上面的每相值与磁链。
- `ENC_MECH_RPM_MAX` 由旧假设 3000 rpm 改为铭牌最大转速 **1028 rpm**；跳变判据
  `B_MAX_LSB` 随之从 45 降到 19。`MAX_BLIND_US` 仍保持 50 µs（1 帧），不因电机变慢
  而放宽。
- 额定/堵转电流与扭矩只作记录和后续限流策略输入；当前电流环没有在线扭矩模型。
