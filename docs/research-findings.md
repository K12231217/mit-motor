## 2. 文献侧结论

### 2.1 P1 三相电流采样方法与 PWM 窗口（13 篇）

- 主体是**单直流母线电阻重构**（1-shunt），驱动它们的约束是「最小有效矢量持续时间」——与我们「零矢量窗口」同源，但更苛刻。
- 经典链条：review 与方案（1997, 243 引）→ 测量电压矢量（2006, 180）→ 电压注入（2009, 160）→ **零矢量采样**（2016, 139）→ 混合 PWM 扩展量程（2019, 31）→ 固定采样时刻（2025）。
- 对我们是**间接价值**：三低边 + 三 ADC 把「重构」整个消掉了。真正要借的是两条：① 零矢量采样窗口的判据；② 占空比受限时的公认对策（混合 PWM / 电压注入）——我们论证「关节低速大电流，不需要」即可，而不是「不知道有这个限制」。

### 2.2 P2 集成驱动的片上采样（6 篇）

- 片上 sense-FET / sense-HEMT 的比例在 **1200:1** 量级（GaN 三相驱动 IC、BLDC 片上采样、步进驱动 IC）。
- MP6540 的 **1:9200** 比它们低约 8 倍：同样的相电流，我们的输出电压小一个数量级，这就是 7.4 mA/LSB 的来源。
- 结论：集成采样同样需要偏置/增益标定；本组没有 MP6540 专项文献（预期内，该芯片在学术界几乎无人使用），其特性以手册为准。

### 2.3 P3 零和约束下的相对增益标定（9 篇，核心）

误差分两类，信号结构不同：**offset** 在 dq 上表现为基频分量，**scaling/gain** 表现为二次谐波。2026 年的 DPCC 论文明确写道「两类误差信号结构不同，同时在线补偿仍然困难」——这句话就是本毕设的问题陈述。

方法族：

| 方法 | 代表 | 依赖 |
|---|---|---|
| 多传感器互校准 | 2019, 57 引, `10.1109/tie.2019.2896320` | 需要**异构冗余**（直流母线 + 两相）|
| 选择性自校准（offset）| 2026, `10.36227/techrxiv.176799853.36374823/v1` | 依靠零矢量/停机窗 |
| 增益误差传播机制 + 轻量补偿 | 2026, `10.1109/jestpe.2026.3694221` | 前馈补偿，需已知误差模型 |
| 自适应 ESO 补偿 offset | 2023, 34 引, `10.1109/tie.2023.3277084` | 观测器模型 |
| 调制切换协同标定 | 2026, `10.1109/tie.2026.3695228` | 多电机/多工况协同 |

**关键发现**：这些方法几乎都依赖额外冗余或主动注入。我们只有三路同构低边采样 + 零和约束：每个样本 3 个观测、2 个独立方程、2 个未知相对增益——**恰好定解，没有冗余**。

后果有两个，都影响架构：

1. 单样本层面**不存在残差**（任何样本都能解出一组增益），所以「残差超限」不能作为可信判据。
2. 可信性只能来自**时间与工况的多样性**：多幅值、多方向、多工况下估计值的一致性；以及激励是否充分到让噪声不主导。

### 2.4 P4 绝对/共模增益与外部基准（6 篇）

- 关注的是采样延迟误差、精度不确定性、死区畸变、共模电压。典型结论：重构得到的相电流与理想电流存在**采样时刻差**，需要补偿（2026, 12 引, `10.1109/tie.2026.3658698`）。
- 对我们是**反面优势**：三 ADC 同步转换使采样时刻差 ≈ 0，这一类误差在本设计里不存在——可以写成设计论证。
- 绝对增益仍然无法从零和约束得到，必须外部基准（分流器 + 万用表）。与 README 的边界声明一致。

### 2.5 P5 校准冻结、故障检测与安全处理（7 篇）

- 标准结构：**观测器残差 → 检测 → 隔离 → 容错控制**（2010, 259 引；2013, 375 引；2018, 274 引；2017, 142 引）。
- 与我们的「冻结 → 诊断 → 锁存」同构，但他们的残差来自**模型**（有冗余），我们的残差不能来自被估计量本身（见 2.3）。这决定了我们必须引入一个独立观测通道或时间一致性判据。

## 3. 交叉结论（直接改架构的 5 条）

1. **标定拆两级**：offset（成熟方法多，先做）与 relative gain（缺冗余，靠时间多样性）。论文里必须分开陈述，不能混成一句「自校准」。
2. **可信判据不能是残差**：恰恰定解意味着残差恒为零。放行条件改为三条独立判据——激励充分性、跨工况一致性、估计值漂移速率。
3. **占空比上限有公认对策**：混合 PWM / 电压注入。我们不用，但要在论文里论证不需要。
4. **三 ADC 同步是设计优势**：文献里一整类「采样延迟误差」问题在本设计不存在。
5. **绝对增益必须外部基准**：与现有边界声明一致，台架协议（分流 + 万用表）就是这个基准的唯一来源。
